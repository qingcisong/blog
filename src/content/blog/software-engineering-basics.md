## Software Engineering

When we start with a big term, it's usually confusing. Breaking apart this word, software engineering isn't about just writing code—it's a collaboration.

There are 3 major areas collaborating:
- HTML
- CSS
- JavaScript (JS)

### HTML

**For information**: This is an acronym for HyperText Markup Language.

**For understanding**: This is the part where you decide the structure and templates of the page. This includes defining where is the title, the contents. We can see the HTML as bricks of building software.

![Code example showing header pointing to the title section of a website](/blog-placeholder-1.jpg)

### CSS

After you have this house of bricks, we want to decorate it.

**How do we want our software to be seen?**

We decide how the elements (bricks) look like—the size, the color. We decide how the screens may switch or change colors. We can decide the very detailed alignments and spaces in between the elements to make it aesthetically pleasing.

### JavaScript

In the beautiful house that we now have, we need "electric wires" to make the house adapt to our changes. Otherwise, you can't even turn the lights on when you click on the light button.

*[Image placeholder: A scene showing someone unable to turn on the lights. In the dark with a ghost nearby, imagining the ghost would disappear if the lights turned on, but the lights won't work—making it even scarier]*

So JS makes the software interactive. It is responsible for making changes when the user clicks on a certain button, when the contents have to be updated, etc.

A software, either an app or a website, needs these three parts to function. In the following posts, I'll slowly explore how these parts come together to become the webpage we see.
